Video Station alternative for DSM 7.2.2 and laterDSM 7.2.2 이후 Video Station 대안

Video Station can't be installed on DSM 7.2.2 and later. Ownstream is a free alternative for watching your Synology NAS videos on iPhone, iPad and Apple TV: it automatically uses File Mode when Video Station is absent.DSM 7.2.2 이후에는 Video Station을 설치할 수 없습니다. Ownstream은 Video Station이 없으면 자동으로 파일 모드를 사용해 iPhone·iPad·Apple TV에서 Synology NAS 영상을 무료로 재생합니다.

How folders become librariesNAS 폴더가 라이브러리로

File Mode builds libraries from video files in your NAS folders and needs File Station permission. Open Movies, TV Shows or Home Videos to connect a suggested folder such as /video/Movies, or choose a folder yourself.파일 모드는 NAS 폴더의 영상 파일로 라이브러리를 구성하며, File Station 권한이 필요합니다. 영화·TV 프로그램·홈 비디오를 열어 /video/Movies 같은 추천 폴더를 연결하거나 직접 폴더를 고르세요.

Your own personal TMDB key is optional. In File Mode, add it to fetch posters and plots; you can use the app without it.본인의 개인용 TMDB 키는 선택 사항입니다. 파일 모드에서 포스터·줄거리를 가져오려면 키를 추가하세요. 키 없이도 앱을 사용할 수 있습니다.

Set up File Mode step by step파일 모드 설정 순서

  1. Check that your DSM account has File Station permission. Use your existing DSM account to sign in; no new app account is needed.DSM 계정에 File Station 권한이 있는지 확인하세요. 기존 DSM 계정으로 로그인하며, 앱 회원가입은 필요 없습니다.
  2. Open Ownstream and enter your NAS address. On your home Wi-Fi, an IP address such as 192.168.0.10 works; without a port or scheme, the app uses HTTPS on DSM port 5001. Enter your custom port if you changed it.Ownstream을 열고 NAS 주소를 입력하세요. 집 안 Wi-Fi에서는 192.168.0.10 같은 IP 주소를 쓸 수 있습니다. 포트와 scheme을 생략하면 HTTPS와 DSM 포트 5001을 사용하며, 포트를 바꿨다면 해당 포트를 입력하세요.
  3. Without Video Station, File Mode starts automatically. Open Movies, TV Shows or Home Videos that has no folder yet, then connect a suggested folder or choose one yourself.Video Station이 없으면 파일 모드가 자동으로 시작됩니다. 아직 폴더가 없는 영화·TV 프로그램·홈 비디오를 열고 추천 폴더를 연결하거나 직접 고르세요.
  4. On iPhone or iPad, use Settings › Library Folders to change folders or Add Library to create a named library. On Apple TV, connect folders and add libraries in Settings › Libraries. Deleting a library never deletes your NAS files.iPhone·iPad에서는 설정 › 라이브러리 폴더에서 폴더를 바꾸거나 라이브러리 추가로 이름을 정해 만드세요. Apple TV에서는 설정 › 라이브러리에서 폴더를 연결하고 추가할 수 있습니다. 라이브러리를 삭제해도 NAS 파일은 지워지지 않습니다.
  5. For posters and plots, optionally add your personal TMDB API Key or API Read Access Token in the app settings. On iPhone and iPad, use Settings › Movie Info Key (TMDB).포스터·줄거리가 필요하면 앱 설정에 본인의 TMDB API Key 또는 API Read Access Token을 선택적으로 추가하세요. iPhone·iPad에서는 설정 › 영화 정보 키 (TMDB)를 사용합니다.
  6. Open the library, choose a video and press play. TV shows use the folder structure TV folder/Show name/(Season folder)/Episode files.라이브러리에서 영상을 골라 재생하세요. TV 프로그램은 TV 폴더/작품명/(시즌 폴더)/에피소드 파일 구조로 읽습니다.

Frequently asked questions자주 묻는 질문

Do I need a TMDB key to watch videos?영상을 보려면 TMDB 키가 필요한가요?

No. A personal TMDB key is optional; in File Mode it is needed to fetch posters and plots.아니요. 개인용 TMDB 키는 선택 사항이며, 파일 모드에서 포스터와 줄거리를 가져올 때 필요합니다.

Can I search online for subtitles in File Mode?파일 모드에서도 인터넷 자막을 검색할 수 있나요?

Yes. On iPhone, iPad and Apple TV, File Mode searches OpenSubtitles directly with your own free OpenSubtitles API key (Settings › Subtitles). The subtitle is saved next to the video on your NAS. Embedded subtitles and matching subtitle files work in both modes.네. iPhone·iPad·Apple TV에서 파일 모드는 본인의 무료 OpenSubtitles API 키(설정 › 자막)로 OpenSubtitles에서 바로 찾고, 찾은 자막은 NAS의 영상 옆에 저장합니다. 내장 자막과 같은 이름의 자막 파일은 두 모드 모두 지원합니다.

Can I resume on another device?다른 기기에서도 이어볼 수 있나요?

Yes, with the same NAS account. File Mode saves watch progress in a .jnology folder on your NAS. Library lists are saved in the DSM home folder at /home/.jnology.네. 같은 NAS 계정을 사용하세요. 파일 모드의 재생 기록은 NAS의 .jnology 폴더에 저장됩니다. 라이브러리 목록은 DSM 홈 폴더의 /home/.jnology에 저장됩니다.
